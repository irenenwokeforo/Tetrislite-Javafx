## Background
They say that when learning something new, it’s best to learn from the master, so I decided to recreate one of my favourite games, Tetris. My inspiration for this project came from taking a course, ECE 325, where I had the honour of learning object-oriented programming in Java with Professor Bezemer. Unlike my previous experience with coding classes, the professor was able to explain concepts clearly in an engaging manner whilst creating a safe space to ask questions. I had so much fun creating this project, as I also discovered how much I love creating GUIs! My wonderful sister, who is an aspiring musician, helped me develop the background music for the game (thanks sis).
    
As I kept adding new features to the game, I noticed the rendering and handling of user input getting slower, and slower, and slower! I would constantly review my project and think to myself... "How can I optimize this code?". Over time I still plan on doing my best to speed up the graphics but for now this project inspired me to learn a bit more about how things work on a lower level under the hood. It also made me appreciate game developers who produce intricate games with smooth graphics so much more! Thanks for reviewing this, more projects to come.
## How to Play
1. Download the repository and open it in your IDE
2. In the terminal run: `mvn clean javafx:run`
3. Play Tetris to your heart's content!
